# HashChat colours

| Token | Hex | Use |
|-------|-----|-----|
| `bg` | `#0A0A0A` | App background, icon plate |
| `bg-elevated` | `#1A1A1A` | Panels, cards |
| `accent` / `gold` | `#FFD700` | Primary accent (titles, own bubbles, icons) |
| `text` | `#F5F5F5` | Primary text |
| `text-dim` | `#A0A0A0` | Secondary text |
| `danger` | `#FF4D4D` | Wipe / destructive (use sparingly) |
| `ok` | `#3DDC97` | Tor up / encrypted (optional) |

No blue as brand colour. Layout energy may resemble mainstream messengers; palette is black + yellow/gold.
